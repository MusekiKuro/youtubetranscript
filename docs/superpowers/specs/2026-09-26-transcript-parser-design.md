# Спецификация: веб-парсер транскриптов видео

Дата: 2026-09-26
Статус: утверждён (устно, в чате)

## Цель

Веб-приложение, которое по списку ссылок на видео извлекает транскрипты
(субтитры) и показывает их на странице с таймкодами, возможностью скачать
отдельно или ZIP-архивом.

Владелец: пользователь, работающий в браузере (локально или в локальной сети).

Успех = ссылка → читаемый транскрипт с таймкодами за секунды, без ручной работы;
видео без субтитров автоматически расшифровывается через Whisper API.

## Объём (scope)

Входит:

- Приём списка ссылок (массовая вставка).
- Извлечение субтитров через yt-dlp: авторские → автосубтитры.
- Резервная расшифровка через OpenAI Whisper API, если субтитров нет.
- Пакетная обработка: до 5 ссылок параллельно, статус по каждой.
- Отображение транскрипта на странице с таймкодами.
- Скачивание: `.srt`, `.txt`, ZIP для всего пакета.
- Кэш транскриптов на диске.
- Переключение языка субтитров, если доступно несколько.

Не входит:

- Скачивание видеофайлов.
- Парсинг комментариев, метаданных, просмотров.
- Пользовательские аккаунты, авторизация.
- Публичный деплой (HTTPS, домен) — только локальный запуск.
- Очередь задач/Celery, база данных (кэш — обычные JSON-файлы).

## Архитектура

```
Браузер (одна HTML-страница)
   │  POST /api/parse {links[], lang?}
   ▼
FastAPI (uvicorn)
   ├── TranscriptionService — ядро, цепочка источников:
   │     1. yt-dlp → авторские субтитры (writeautomaticsub=false)
   │     2. yt-dlp → автосубтитры (writeautomaticsub=true)
   │     3. Whisper API: yt-dlp качает ТОЛЬКО аудио → ffmpeg → mp3 →
   │        POST api.openai.com/v1/audio/transcriptions
   │     4. иначе → статус "нет транскрипта"
   ├── BatchJob — ThreadPoolExecutor(5), прогресс по каждой ссылке
   └── /api/jobs/{job_id} — статусы: pending | done | error, progress %
```

### Компоненты

| Компонент | Ответственность | Зависимости |
|---|---|---|
| `app/main.py` | HTTP-роуты, отдача статики | TranscriptionService, BatchJob |
| `app/transcription.py` | Цепочка источников, выбор языка | yt_dlp, whisper_client |
| `app/vtt.py` | VTT/SRT → текст с таймкодами, схлопывание дублей | — |
| `app/whisper_client.py` | Вызов OpenAI API, ретраи | httpx, OPENAI_API_KEY |
| `app/batch.py` | Пакетная обработка, прогресс | transcription |
| `app/cache.py` | Чтение/запись `data/{video_id}.json` | — |
| `static/index.html` | Одна страница UI | fetch к API |

### Формат хранения (кэш)

`data/{video_id}.json`:

```json
{
  "url": "...", "title": "...", "source": "manual | auto | whisper",
  "language": "ru", "segments": [{"start": 72.4, "end": 75.1, "text": "..."}]
}
```

`video_id` извлекается из URL; если yt-dlp не может дать id (экзотический
сайт) — хэш от нормализованного URL.

## Поток данных

1. Пользователь вставляет ссылки → `POST /api/parse`.
2. Сервер создаёт job, возвращает `job_id`, обработка идёт в фоне.
3. UI опрашивает `/api/jobs/{id}` каждые ~500 мс, обновляя таблицу.
4. По клику на строку: `GET /api/transcript/{video_id}?lang=ru` → текст.
5. Скачивание: `GET /api/transcript/{video_id}/download?format=srt|txt`,
   для пакета — `GET /api/jobs/{id}/zip`.

### Формат вывода

- **TXT**: `[MM:SS] реплика` (часы добавляются при необходимости).
- **SRT**: корректная нумерация блоков, `HH:MM:SS,mmm --> HH:MM:SS,mmm`.

## Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Невалидная ссылка / приватное видео | строка `ошибка: <сообщение>`, остальные ссылки обрабатываются |
| Субтитров нет (авто тоже) | скачиваем аудио → Whisper API |
| Whisper API: 429/5xx/сеть | ретрай 2 раза с backoff (1с, 3с), затем статус `нет транскрипта (Whisper недоступен)` |
| `OPENAI_API_KEY` не задан | Whisper-этап пропускается, статус `нет транскриптов` |
| Субтитры на другом языке | отдаём `language` в UI, поддерживаем повторный запрос с `?lang=` |
| Пустой/битый VTT | считаем источник неудачным, идём дальше по цепочке |

## Безопасность

- `OPENAI_API_KEY` только в `.env` (python-dotenv), `.env` в `.gitignore`.
- Сервер слушает `127.0.0.1` по умолчанию.
- Ссылки валидируются (только http/https), путь к кэшу нормализуется —
  `video_id` не может выйти за пределы `data/` (path traversal).
- Запросы в Whisper — только на `api.openai.com`.

## Тестирование

- Юнит: `vtt.py` — фикстуры: чистый VTT, дубли автосубтитров (строка
  повторяется с разной confidence), пустой файл, SRT-вход.
- Юнит: `transcription.py` — цепочка с моками yt-dlp/whisper:
  (а) есть авторские, (б) только авто, (в) ничего → whisper ок,
  (г) whisper падает, (д) ключ не задан.
- Юнит: кэш — повторная ссылка не идёт в сеть.
- Ручная: 3 реальных ссылки (одна точно без субтитров, одна с авторскими,
  одна битая) → проверка статусов, текста, скачивания SRT/TXT/ZIP.

## Технологии

- Python 3.14, FastAPI, uvicorn (уже в системе).
- `yt-dlp` (pip, доустановить), `httpx`, `python-dotenv`.
- ffmpeg — уже установлен (конвертация аудио для Whisper).
- Фронтенд: один HTML-файл, ванильный JS, без сборки.
